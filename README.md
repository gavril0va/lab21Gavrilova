# Практическая работа №21

Автор: Гаврилова Вероника
Группа: ИСП-251

Коллекция List в C#.

 Что реализовано
- ввод и вывод списка задач;
- добавление и вставка;
- удаление по значению и индексу;
- поиск первого совпадения;
- проверка допустимости индексов;
- обработка пустого списка;
- все 3 самостоятельных задания (подсчёт, удаление всех, отбор по длине).

 Короткие ответы
1. у массива размер фиксирован, а List в  можно добавлять/удалять элементы. Количество элементов в List узнать можно через Count, а в массиве  через Length.

2. Remove ищет элемент по его значению и удаляет первое совпадение, а RemoveAt удаляет элемент по его индексу.

3. потому что Insert(Count) добавляет элемент в самый конец списка. А при удалении элемента с индексом Count программа выйдет за границы.
